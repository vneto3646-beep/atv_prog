Faça um sistema web conforme as especificações abaixo

a) use a biblioteca streamlit
b) use o gerenciador de pacotes "uv"
c) use a biblioteca SQLAlchemty para criar classes persistentes
d) configure conexões de banco de dados para o sqlite e para o mysql
e) o sqlite será usado para testes locais
f) o mysql será usado em produção
g) faça páginas de CRUD (create, retrieve, update e delete) para cada entidade do sistema
h) use variável de ambiente para armazenar as configurações de conexão com o banco de dados mysql
i) posteriormente será feito deploy no site recomendado pelo streamlit: https://share.streamlit.io/
j) deve haver o arquivo README.md, explicando como executar o sistema, e falando sobre o sistema
k) deve haver o arquivo .gitignore, com o devido conteúdo
l) coloque os códigos dentro de uma pasta chamada "src"

O sistema deverá tratar deste contexto:

Estudantes desejam organizar uma festa no IFC Campus Blumenau. Para isso, precisam decidir quais alimentos serão vendidos, quem vai fornecer os insumos, quais pessoas vão trabalhar na festa (alunos, pais de alunos, servidores) e qual vai ser o preço de venda dos alimentos. Os insumos vão ser doados.
